Question: what is the learning coefficient of H cosine neurons learning the zero function, and how does it depend on H?

This is the challenge problem set for the second effective-theory lecture. It uses two things from Notebook 5: the Hermite coordinates of a cosine neuron (Exercise 5.2a) and Newton polygons (Exercise 5.3a). Notebook 5’s optional §5.4 (tropical arithmetic) is useful background for 6.1d–f.

Notation. As in Notebook 5: inputs x\sim\mathcal N(0,1), the cosine network f_\theta(x)=\sum_{i=1}^Ha_i\cos(w_ix) with \theta=(a,w)\in[-1,1]^{2H} and the uniform prior, K(\theta)=\|f_\theta\|^2 (learning zero), Z_n=\int\varphi\,e^{-nK}, F_n=-\log Z_n.

6.1 Learning zero with H neurons

Challenge section. Difficulty ●●●◐○ · Importance ●●●●○

Question: what is the learning coefficient \lambda_H of learning zero with H cosine neurons?

Notation: By Notebook 5, Exercise 5.2a.1, learning zero is K=\sum_{j\ge0}M_j^2/(2j)! with moments M_j=\sum_i\tilde a_iw_i^{2j}, \tilde a_i=a_ie^{-w_i^2/2}. Throughout this section the parameters are (\tilde a,w) with the uniform prior on [-1,1]^{2H}, and we drop the tildes. (The cosine network with its own prior differs by the factor e^{-w^2/2}\in[e^{-1/2},1] and a slightly different box; this does not affect anything below.) u_i=w_i^2. N is the number of moments kept, L=\tfrac12\log n.

The answer to be established: \lambda_H=\min\Big(\frac H2,\ \min_{1\le k\le H-1}\Big[\frac{k+1}4+\frac H{4k}\Big]\Big)=\tfrac12\sqrt H+O(1). The first term matters only for H\le2. The upper bound is a construction (Exercise 6.1b). The lower bound goes through a Fourier dual in which the H neurons enter through an H-th power of a single-neuron function (Exercise 6.1c); a tropical estimate of that function (6.1d) turns the problem into a linear program (6.1e). One step, controlling cancellations inside a single neuron, is left as a starred exercise (6.1f). Exercise 6.1g is the punchline: truncated to k_0+1\lesssim\sqrt H field coordinates, the model has \lambda=\tfrac12(k_0+1), exactly as if it were regular in field space.

Exercise 6.1a (Finitely many moments suffice).

  1. Let e_l be the elementary symmetric polynomials of u_1,\dots,u_H. Show that for all j\ge0 M_{j+H}=\sum_{l=1}^H(-1)^{l+1}e_l\,M_{j+H-l}.
  2. Deduce |M_j|\le(H2^H)^{j-H+1}\max_{l<H}|M_l| for j\ge H.
  3. Conclude c\,K_{\rm mom}\le K\le C\,K_{\rm mom} on the whole box, with K_{\rm mom}=\sum_{j=0}^{H-1}M_j^2 and constants depending only on H. Hence \lambda_H is the learning coefficient of K_{\rm mom}, a polynomial in which every M_j has degree at most 2H-1.
Hint

Part 1: each u_i is a root of \prod_{i'}(u-u_{i'})=\sum_{l=0}^H(-1)^le_lu^{H-l}; multiply by a_iu_i^j and sum over i. Part 3: \sum_m x^{2m}/(2m)!=\cosh x.

Solution

1. 0=\sum_ia_iu_i^j\prod_{i'}(u_i-u_{i'})=\sum_{l=0}^H(-1)^le_l\sum_ia_iu_i^{j+H-l}=\sum_{l=0}^H(-1)^le_lM_{j+H-l}, and e_0=1.

2. u_i\in[0,1] gives |e_l|\le\binom Hl\le2^H, so |M_{j}|\le H2^H\max_{1\le l\le H}|M_{j-l}|; induct on j.

3. Upper: \sum_{j\ge H}M_j^2/(2j)!\le\mu^2\sum_j(H2^H)^{2j}/(2j)!\le\mu^2\cosh(H2^H) with \mu^2=\max_{l<H}M_l^2\le K_{\rm mom}; and \sum_{j<H}M_j^2/(2j)!\le K_{\rm mom}. Lower: K\ge\sum_{j<H}M_j^2/(2j)!\ge K_{\rm mom}/(2H-2)!. Comparable losses have the same \lambda and m (their sublevel sets are nested up to a constant rescaling of t).

Exercise 6.1b (Upper bound by construction).

  1. Show \lambda_H\le H/2 (Notebook 5, Exercise 5.2d, with N=H).
  2. Fix 1\le k\le H-1 and s=n^{-1/(4k)}. Show that if |w_i|\le s for all i, then |M_j|\le Hn^{-1/2} for all j\ge k.
  3. For j<k write M_j=s^{2j}m_j with m_j=\sum_ia_iv_i^j, v_i=u_i/s^2\in[0,1]. Show that it suffices to impose |m_j|\le n^{-\frac12(1-j/k)} for j<k to get nK_{\rm mom}=O(1).
  4. Restrict v_1,\dots,v_k to fixed disjoint subintervals of [0,1] and |a_i|\le\delta for i>k, with \delta small depending on H,k. Show that for each such choice of w and of a_{k+1},\dots,a_H, the set of (a_1,\dots,a_k)\in[-1,1]^k satisfying the constraints of part 3 has volume \ge c\prod_{j<k}n^{-\frac12(1-j/k)}=c\,n^{-(k+1)/4}.
  5. Conclude V(C/n)\ge c\,n^{-H/(4k)-(k+1)/4}, hence \lambda_H\le\frac{k+1}4+\frac H{4k}.
  6. A simpler construction imposes |M_j|\le n^{-1/2} on a directly for j<k, without using the smallness of w. What bound does it give, and why is it worse?
Hint

Part 4: for fixed v, (a_1,\dots,a_k)\mapsto(m_j)_{j<k} is the Vandermonde matrix V_k of v_1,\dots,v_k applied to (a_1,\dots,a_k), plus a shift by the contribution of the other neurons. On the restricted set, |\det V_k| is bounded below, so V_k^{-1} is bounded; choose \delta so that the shift, pulled back by V_k^{-1}, stays well inside [-1,1]^k.

Solution

1. At a=0 with distinct |w_i|, (M_0,\dots,M_{H-1}) is a submersion (Notebook 5, Exercise 5.2d.3 with k=H-1).

2. |M_j|\le\sum_i|w_i|^{2j}\le Hs^{2j}\le Hs^{2k}=Hn^{-1/2}.

3. Then |M_j|=s^{2j}|m_j|\le n^{-j/(2k)}n^{-\frac12+\frac j{2k}}=n^{-1/2} for j<k, so nK_{\rm mom}\le k+(H-k)H^2.

4. m=V_k(a_1,\dots,a_k)^\top+b, with b the contribution of neurons i>k, |b|\le H\delta. The constraint set is V_k^{-1}(\text{box}-b), a parallelotope of volume \prod_j2n^{-\frac12(1-j/k)}/|\det V_k|, centred at -V_k^{-1}b, of diameter \le\|V_k^{-1}\|\cdot O(1) for n\ge1. It lies in [-1,1]^k once \|V_k^{-1}\|H\delta is small and n is large. Then \sum_{j<k}\tfrac12(1-j/k)=\tfrac12\big(k-\tfrac{k-1}2\big)=\tfrac{k+1}4.

5. The w-volume is \ge c\,s^H=c\,n^{-H/(4k)} (each w_i ranges over a set of size \asymp s), and the a_{>k}-volume is \asymp\delta^{H-k}. By parts 3–4, the set lies in \{K_{\rm mom}<C/n\}. If V(t)\ge c\,t^{\lambda'} along t=C/n, then \lambda\le\lambda'.

6. Imposing |M_j|\le n^{-1/2} for j<k via a costs n^{-k/2}, so \lambda_H\le\frac k2+\frac H{4k}, minimised at k\approx\sqrt{H/2}: \lambda_H\le\sqrt{H/2}. It ignores that M_j is already of size s^{2j}, so constraint j only needs a relative precision n^{-\frac12(1-j/k)}, not n^{-1/2}.

Exercise 6.1c (The Fourier dual). Let N=H, \phi(a,w)=a\,(1,w^2,\dots,w^{2(N-1)})\in\mathbb R^N, so K_{\rm mom}(\theta)=\big|\sum_{i=1}^H\phi(a_i,w_i)\big|^2.

  1. Show, for y\in\mathbb R^N, e^{-n|y|^2}=(4\pi n)^{-N/2}\int_{\mathbb R^N}e^{i\langle\eta,y\rangle-|\eta|^2/(4n)}\,d\eta .
  2. Deduce \bar Z_n=(4\pi n)^{-N/2}\int_{\mathbb R^N}\chi(\eta)^H\,e^{-|\eta|^2/(4n)}\,d\eta,\qquad\chi(\eta)=\mathbb E_{(a,w)}\,e^{i\langle\eta,\phi(a,w)\rangle}, the expectation over one neuron with the uniform prior.
  3. Show \chi(\eta)=\mathbb E_w\,\mathrm{sinc}\big(P_\eta(w^2)\big), where P_\eta(u)=\sum_{j<N}\eta_ju^j and \mathrm{sinc}(z)=\sin z/z. Conclude that \chi is real, |\chi|\le1, and \bar Z_n\le(4\pi n)^{-N/2}\int|\chi(\eta)|^He^{-|\eta|^2/(4n)}d\eta,\qquad |\chi(\eta)|\le\mathbb E_w\min\big(1,|P_\eta(w^2)|^{-1}\big).
  4. Check H=1: compute \bar Z_n exactly from part 2 and recover \lambda_1=\tfrac12.
  5. Explain in one sentence what the dual has done to the cancellations between neurons noted at the end of Notebook 5, §5.3.
Hint

Part 1: complete the square, or recall that the Fourier transform of a Gaussian is a Gaussian. Part 3: integrate over a\in[-1,1] first; \langle\eta,\phi(a,w)\rangle=a\,P_\eta(w^2). Part 4: \int_{\mathbb R}\mathrm{sinc}=\pi.

Solution

1. Each coordinate: \int e^{i\eta y-\eta^2/(4n)}d\eta=\sqrt{4\pi n}\,e^{-ny^2}.

2. Apply part 1 with y=\sum_i\phi(\theta_i), take the prior expectation and use Fubini (the integrand is bounded by e^{-|\eta|^2/4n}). Since the \theta_i are independent, \mathbb E\,e^{i\langle\eta,\sum_i\phi(\theta_i)\rangle}=\chi(\eta)^H. Here \bar Z_n=Z_n since \min K_{\rm mom}=0.

3. \tfrac12\int_{-1}^1e^{iap}da=\sin p/p. So \chi(\eta)=\mathbb E_w\,\mathrm{sinc}(P_\eta(w^2)), real, and |\mathrm{sinc}(z)|\le\min(1,1/|z|). Since Z_n>0, Z_n=|Z_n|\le the integral of the absolute value.

4. N=1, P_\eta=\eta: Z_n=(4\pi n)^{-1/2}\int\mathrm{sinc}(\eta)e^{-\eta^2/4n}d\eta\to(4\pi n)^{-1/2}\pi, so \bar F_n=\tfrac12\log n+O(1).

5. On the primal side neurons cancel each other inside every moment; in the dual they enter only through the H-th power of a one-neuron function, so all remaining cancellation is inside a single univariate polynomial P_\eta.

Exercise 6.1d (One neuron, tropically). Write \ell_j=\log_+|\eta_j|=\max(0,\log|\eta_j|) and \Phi(\ell)=\min_{y\le0}\Big[\max\big(0,\max_j(\ell_j+2jy)\big)-y\Big].

  1. Suppose |P_\eta(u)|\ge c\,\max_j|\eta_j|u^j on [0,1] for some c\in(0,1] (no cancellation). Show |\chi(\eta)|\le\frac2c\,e^{-\Phi(\ell)}.
  2. (Staircase.) For 0<Y\le L/2 let \ell_0=0 and \ell_j=\min(L,2jY) for j\ge1. Show \Phi(\ell)=Y. What do these \eta correspond to, as polynomials P_\eta?
  3. Why is |\chi(\eta)| not approximated by the measure of \{w:|P_\eta(w^2)|<1\}? Compare the two for P_\eta(u)=r^{1/2}+ru.
Hint

Part 1: substitute w=e^y, so dw=e^ydy, and note that y\mapsto\max(0,\max_j(\ell_j+2jy))-y is convex and piecewise linear with slopes in \{-1,1,3,5,\dots\}, never 0. Coordinates with |\eta_j|<1 only contribute terms that are already below the 0 in the max.

Solution

1. |\chi|\le\int_0^1\min(1,|P(w^2)|^{-1})dw\le\frac1c\int_0^1\min\big(1,(\max_j|\eta_j|w^{2j})^{-1}\big)dw. With w=e^y the integrand is \exp\big(y-\max(0,\max_j(\log|\eta_j|+2jy))\big), and replacing \log|\eta_j| by \ell_j changes nothing, because when |\eta_j|<1 both \log|\eta_j|+2jy and 2jy are \le0. The exponent is -g(y) with g convex, piecewise linear, with slopes -1 (from the 0 and j=0 pieces) and 2j-1\ge1; so \int e^{-g}\le2e^{-\min g}=2e^{-\Phi}.

2. At y=-Y: \ell_j-2jY\le0 for all j, so the bracket is Y. For -Y<y\le0 the j=1 term gives at least 2Y+2y-y=2Y+y>Y; for y<-Y the bracket is at least -y>Y. With r=e^L and k=L/(2Y), these are polynomials P(u)\approx\sum_j(u/u_*)^j with u_*=r^{-1/k}, coefficients capped at r: |P|\lesssim1 for u\lesssim u_* and |P| grows like (u/u_*)^k beyond. Then |\chi| is about the w-measure of \{w^2\lesssim u_*\}, i.e. r^{-1/(2k)}=e^{-Y}.

3. \min(1,1/|P|) has heavy tails: where |P| is large but not huge, it still contributes. For P=r^{1/2}+ru the set \{|P|<1\} is empty, while \int_0^1\min(1,1/P(w^2))dw\asymp(r^{1/2}r)^{-1/2}=r^{-3/4}=e^{-\Phi} with \ell=(L/2,L). Using sublevel volumes instead of the tails gives wrong learning coefficients (try it for H=2, where the answer is \lambda_2=1).

Exercise 6.1e (The linear program).

  1. Split \mathbb R^N into the regions \{|\eta_j|\in[e^{\ell_j},e^{\ell_j+1})\} (with |\eta_j|<1 for \ell_j=0). Assuming the bound of 6.1d.1 for every \eta, show \log\bar Z_n\le-NL+\max_{\ell\in[0,L]^N}\Big[\sum_j\ell_j-H\,\Phi(\ell)\Big]+O(\log\log n), so that \lambda_H\ge\frac1{2L}\big(NL-\max[\dots]\big) asymptotically.
  2. Show that \Phi is convex, so the maximisation is a linear program in (\ell,y,t): maximise \sum_j\ell_j-Ht subject to t\ge-y, t\ge\ell_j+2jy-y, y\le0, 0\le\ell_j\le L.
  3. Show that the optimum is attained on a staircase of Exercise 6.1d.2 with Y=L/(2k) for some k\in\{1,\dots,N-1\}, or at \ell=0. Conclude \lambda_H\ge\min\Big(\frac N2,\ \min_{1\le k\le N-1}\Big[\frac{k+1}4+\frac H{4k}\Big]\Big), which with N=H matches Exercise 6.1b.
  4. Show \lambda_H=\tfrac12\sqrt H+O(1) and describe the dominant stratum.
Hint

Part 1: a region with given \ell has volume \asymp e^{\sum\ell_j}; the Gaussian factor kills \ell_j\ge L+\log L; there are O((\log n)^N) regions. Part 3: \Phi(\ell)\le Y iff there is y'\in[0,Y] with \ell_j\le2jy'+Y-y' for all j. For fixed Y, maximise \sum_j\min(L,2jy'+Y-y') over y'; then the objective is a concave piecewise linear function of Y with breakpoints at Y=L/(2k).

Solution

1. On the region labelled \ell, |\chi|^H\le(2/c)^He^{-H\Phi(\ell)} and the volume is \le e^{N+\sum_j\ell_j}. Regions with some \ell_j>L+\log L have Gaussian factor \le e^{-L^2} and contribute O(1) in total after the prefactor. The remaining O\big((L+\log L)^N\big) regions contribute at most e^{\max[\cdots]+O(N\log L)} (extend the max to [0,L+\log L]^N; this changes it by O(N\log L) since the objective is Lipschitz). Finally (4\pi n)^{-N/2}=e^{-NL+O(1)}, and \bar F_n=-\log\bar Z_n.

2. (\ell,y)\mapsto\max(0,\max_j(\ell_j+2jy))-y is a maximum of affine functions, hence jointly convex; minimising over y preserves convexity. The epigraph formulation is the stated LP.

3. With y=-y', \Phi\le Y iff \max(0,\max_j(\ell_j-2jy'))+y'\le Y for some y'\ge0, i.e. y'\le Y and \ell_j\le2jy'+(Y-y'). For fixed Y, \sum_j\min(L,2jy'+Y-y') has derivative in y' equal to -1 (from j=0, if uncapped) plus 2j-1\ge1 for each uncapped j\ge1; it is maximised at y'=Y unless all j\ge1 are capped, and in that case one checks directly that the value does not exceed the k=1 staircase. So the optimum for given Y is the staircase, with value G(Y)=\sum_{j=1}^{N-1}\min(L,2jY)-HY: concave, piecewise linear, with breakpoints Y=L/(2k). At Y=0, G=0, giving \lambda\ge N/2. At Y=L/(2k), G=\tfrac{k+1}2L+(N-1-k)L-\tfrac H{2k}L,\qquad\frac{NL-G}{2L}=\frac{k+1}4+\frac H{4k}. The code cell solves the LP numerically and confirms the closed form.

4. \frac{k+1}4+\frac H{4k} is minimised near k=\sqrt H, with value \tfrac12\sqrt H+\tfrac14+O(1/\sqrt H) over integers; since \tfrac H4+\tfrac12\le\tfrac H2 for H\ge2, the N/2 term is irrelevant then. The dominant stratum has k\approx\sqrt H: dual vectors whose polynomial P_\eta is a staircase making the single-neuron function \chi decay like |\eta|^{-1/(2\sqrt H)}, on a set of \eta of relative log-volume \approx\sqrt H/2. On the primal side (6.1b) it is the set where all |w_i|\lesssim n^{-1/(4\sqrt H)} and the first \approx\sqrt H moments cancel to graded precision.

The one-neuron picture. Each stratum of dual vectors is a point (q,y): q is the valuation of the one-neuron function on the stratum, |\chi|\approx r^{-q} at |\eta|\approx r, and y\le0 is the stratum’s log-volume relative to the ball of radius r, per unit of \log r. For \deg P_\eta\le4 (N=5) the points are the staircases of Exercise 6.1d.2, where P_\eta vanishes to order k at u=0, at \big(\tfrac1{2k},-\tfrac{k+1}2\big) for k=1,\dots,4, and the bounded region |\eta|=O(1) at (0,-N). (Generic \eta sit at (1,0), off the left panel; they matter only for H\le2.)

The width enters only through |\chi|^H, which shears the picture, (q,y)\mapsto(q,\,y-Hq); by Exercise 6.1e the highest point after the shear gives \lambda_H=-\tfrac12\max(y-Hq). Unsheared, this is the point where a line of slope H touches the configuration from above (left panel). As H grows the touching point moves down the staircase, switching from k to k+1 at H=k(k+1), and at H=N(N-1)=20 it reaches the bounded region, after which \lambda=N/2: Exercise 6.1g. Dually, each stratum is a line \lambda=\tfrac12(Hq+|y|) in the width, and \lambda_H is their lower envelope (right panel). The cell computes the valuations numerically, from \mathbb E_w\min(1,|P_\eta(w^2)|^{-1}) at two scales r; the volumes are the constraint counts of Exercise 6.1d.2.

N = 5                                    # P_eta has degree <= 4
def chi_bound(eta):
    # E_w min(1, 1/|P_eta(w^2)|), w uniform on [0,1], integrated on a log grid in w
    lw = np.linspace(-40, 0, 40001); w = np.exp(lw)
    P = sum(e * w**(2 * j) for j, e in enumerate(eta))
    return np.sum(np.minimum(1, 1 / np.abs(P)) * w) * (lw[1] - lw[0])
def staircase(r, k):
    return [1.0] + [r**min(1.0, j / k) for j in range(1, N)]
r1, r2 = 1e8, 1e16
q_num = np.array([-np.log(chi_bound(staircase(r2, k)) / chi_bound(staircase(r1, k))) / np.log(r2 / r1) for k in range(1, N)])

Exercise 6.1f* (The missing step: cancellation inside one neuron). The assumption of 6.1d.1 fails when P_\eta has roots of high order in (0,1].

  1. (Sublevel sets.) Let g\in C^m(I) with |g^{(m)}|\ge\mu>0 on an interval I. Prove |\{x\in I:|g(x)|<\delta\}|\le C_m(\delta/\mu)^{1/m}.
  2. (Heuristic.) Suppose P_\eta has a root of order k at u_0\in(0,1], at scale |\eta|\approx r. Argue that |\chi(\eta)|\approx r^{-1/k}, rather than r^{-1/(2k)} for a root at u_0=0, and that such \eta form a set of relative log-volume about \big(\tfrac{k+1}2-\tfrac1k\big)\log r. Show that the resulting candidate value \frac H{2k}+\frac{k+1}4-\frac1{2k} is never below the u_0=0 value \frac H{4k}+\frac{k+1}4 when H\ge2.
  3. (Open-ended.) Turn 1 and 2 into a proof of the lower bound in Exercise 6.1e.
Hint

Part 1: induction on m. The set where |g^{(m-1)}|<\beta is an interval of length \le2\beta/\mu; on each of the at most two remaining intervals, apply the case m-1 with \mu replaced by \beta; then choose \beta=\mu^{(m-1)/m}\delta^{1/m}. Part 2: near w_0=\sqrt{u_0}\ne0 the map w\mapsto w^2 is a diffeomorphism, so w-measure equals u-measure up to constants; the position u_0 is a free parameter, which returns one factor of r^{1/k} in volume.

Solution

1. m=1: g is monotone, so the set is an interval, of length \le2\delta/\mu. Step: |\{|g|<\delta\}|\le2\beta/\mu+2C_{m-1}(\delta/\beta)^{1/(m-1)}; with the stated \beta both terms are multiples of (\delta/\mu)^{1/m}.

2. Near u_0, P\approx r(u-u_0)^k, so \int\min(1,1/|P|)\,du\asymp r^{-1/k}, and the same in w. The Taylor coefficients of P at u_0 must satisfy |P^{(j)}(u_0)/j!|\lesssim r^{j/k} for j<k: relative to size r, a factor r^{-(1-j/k)} each, total r^{-(k+1)/2}, times r^{1/k} for the freedom in u_0 at resolution r^{-1/k}. With q=1/k and A=\frac{k+1}2-\frac1k, the contribution to the exponent is \tfrac12(Hq+A)=\frac H{2k}+\frac{k+1}4-\frac1{2k}, which exceeds \frac H{4k}+\frac{k+1}4 by \frac{H-2}{4k}\ge0.

3. Left open.

def lam_lp(N, H, L=1.0):
    # maximise sum(l) - H t  s.t.  t >= -y,  t >= l_j + (2j-1) y,  y <= 0,  0 <= l_j <= L ; return (N L - max)/(2L)
    nv = N + 2; c = np.zeros(nv); c[:N] = -1; c[N + 1] = H
    A = [np.r_[np.zeros(N), -1, -1]] + [np.r_[np.eye(N)[j], 2 * j - 1, -1] for j in range(N)]
    res = linprog(c, A_ub=np.array(A), b_ub=np.zeros(N + 1), bounds=[(0, L)] * N + [(None, 0), (None, None)])
    return (N * L + res.fun) / (2 * L)

def lam_closed(N, H):
    return min([N / 2] + [(k + 1) / 4 + H / (4 * k) for k in range(1, N)])

def chi(eta, m=2_000_001):
    # E_w sinc(P_eta(w^2)), w uniform on [-1,1]; log-spaced nodes near 0 plus a uniform grid
    w = np.concatenate([np.logspace(-12, -3, 200001), np.linspace(1e-3, 1, m)])
    P = sum(e * w**(2 * j) for j, e in enumerate(eta))
    trap = getattr(np, "trapezoid", None) or np.trapz
    return trap(np.sinc(P / np.pi), w)
